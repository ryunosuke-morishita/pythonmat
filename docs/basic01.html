はじめに

今回はpythonとはから始まり、基本文法・演算子までをまとめる。

pythonとは

　pythonとはRと同じインタプリタ言語である。インタプリタ言語の特徴としては記述が簡単という点が挙げられるだろう。その他にはコンパイル言語と呼ばれるCやJavaなどが存在する。コンパイル型言語はインタプリタ言語に比べ記述が一般的には難しい。その代わり、コンパイルした後のコードを動かすため処理が速い点がメリットとして挙げられる。 　 　現在のpythonはpython3であり、python2に修正が加えられ使いやすくなっている。またパッケージ管理はpipが主流？であったが、今はどうやらuvで管理するのが良いらしい。ただし注意点としてはuvはまだバージョンが1を超えていないため注意が必要である。（唐突に極端な変化が加えられて動かなく可能性があるため） 　この勉強会ではuvを使っていきたいと考えているため、この資料もパッケージをとってくる際はuvの記法になっていることをあらかじめ了承いただきたい。

仮想環境とパッケージ管理

　ここでは勉強会で用いる仮想環境とパッケージ管理について簡単に記述する。勉強会では前でも述べたようにuvを使用する。uvは公式サイトに従ってターミナルから入手できる。 　uvのメリットはたくさんある。その中でも、パッケージ管理が楽であることと、処理が速いことが挙げられるだろう。pythonも仮想環境もパッケージ管理もuv1つで行うことができる。 　uvをダウンロードできたら任意のディレクトリを作成し、そこにuv環境を構築する。まずはuv initでプロジェクトを作成し、uv venv --python **でプロジェクトのpythonのバージョンを指定しながら仮想環境を構築できる。特定のバージョンのpythonを扱いたい時は、uv python install **でpythonをインストールできる。 　パッケージ管理はuv add **で行う。

実際に動かす

　pythonを実際に動かしてみる。例によって「Hello, World!」とでも返すようなものを書いてみよう。

print("Hello,World!")
Hello,World!

　実際に動いただろうか。もし動かなかった場合は自分が参照しているpythonの場所を確認して設定し直して欲しい。

変数と代入

　変数とはその名前の通りに変化する値のことである。ただし数値ではなくていい。pythonにおいて変数を扱うには以下のように記述する。

x = 10
print(x)
10

ここで、xは変数である。このxと10を繋いでいる=は代入演算子と呼ばれ、右辺を左辺に格納する役割を持つ。

ちなみにRの記述をすると以下である。

x <- 10
print(x)
[1] 10

であり、代入演算子は<-である。

=であるが、pythonの中ではこれは式を表していないことに注意されたい。なので後ほど詳しく書くが、以下の文は正しい記法である。

x = 2
x = x + 1
print(x)
3

　また、代入についてpythonは右辺そのものを左辺に格納していない。メモリ上にあるアドレスを格納している。この性質を理解するために以下の文を見てほしい。

num1 = 10
num2 = num1

print(id(num1))
4362807888
print(id(num2))
4362807888

以下の文もこの性質によりかける。

x = [1, 2, 3]
y = x
y.append(4)

print(x)
[1, 2, 3, 4]
print(y)
[1, 2, 3, 4]

これをRでかくとこうなる。

x <- c(1, 2, 3)
y <- x
y[4] <- 4

print(x)
[1] 1 2 3
print(y)
[1] 1 2 3 4

これで代入についての概要は理解できたのではないだろうか。

　またデータ型の分類が複数存在する。例としては整数型や、文字列型などである。これら型の値のことをリテラルと呼ぶ。加えてそれぞれの型には性質がある。

これら性質はこれからも扱っていくのでイメージできるようにしておきたい。例えば、リストはコンテナーでミュータブル型であり、タプルは順序つきのリストでイミュータブル型である。

演算子

　ここでは演算子を扱う。まとめると以下の Table 2 である。

　これは数値以外でも用いることができるが組み合わせによっては演算できないものが存在する。

print(15 + "30")
TypeError: unsupported operand type(s) for +: 'int' and 'str'

以下のコードは上の文を改め数値型と文字型に直して演算したものである。

print(15 + int("30"))
45
print(str(15) + "30")
1530

　算術演算については上の通りであるが、コンピュータ上（主にプログラミング）においては小数の演算には注意されたい。簡単に理由を説明しておくと、コンピュータ上で扱っている数値は我々の10進法とは違い2進法で基本的には動いている。例えば我々は0.1 = 1/10なので扱いやすいが、コンピュータでは扱いにくい数値である。それは位が\frac{1}{2}, \ \frac{1}{4}, \cdotsとなるためである。
