1 制御構文

1.1 条件分岐

　ここまでのプログラムは記述された順に処理して実行していた。しかし、実際はユーザーからの入力値や実行環境、その他条件に応じて、処理を変えるだろう。そのための処理の仕方を今回は学ぶ。

1.1.1 単純分岐

ifは与えらえれた条件がTrue/Falseイズてであるかによって、実行すべき処理を決める命令である。

i = 10 #10をiに代入
if i == 10:
    print("変数iは10です。")
else:
    print("変数iは10ではありません。")
print("End")
変数iは10です。
End

今は「変数iが10である」という命題が真であったため、Trueのときの文が実行された。そして、elseの部分は実行されずにprint("End")が返されこの文全体の実行が終了したのである。elseは”さもなくば〜“であり、命題が偽であった場合に実行される。次はiが10以外であるときを見てみよう。

i = 5 #iに10以外、すなわち5を代入
if i == 10:
    print("変数iは10です。")
else:
    print("変数iは10ではありません。")
print("End")
変数iは10ではありません。
End

今度は「変数iが10である」という命題が偽であったため、else以降が実行され文全体が終了した。これが単純分岐である。

ifは複合文のの一種である。複合文とは配下に複数のぶんをもち、それらの文を実行するかどうかを決めるための文のことである。実践的なコードはこの複合文の組み合わせによって構成される。

Pythonにおいてはインデントは重要な意味をなす。複合文は節、ヘッダー、ブロック（スイート）で基本構成される。上の文においてはif, elseがヘッダー。それ以下の文であるprint 〜〜がブロックと呼ばれる。そしてヘッダーとそのブロックの塊を節という。このブロックの部分をインデントを用いて表す。

空ブロックはpass命令で表す。ブロックの中に何も書かないとエラーになる。何も実行したくない場合はpassを用いて表す。以下を見てみよう。

i = 10 
if i == 10:
    
else:
    print("変数iは10ではありません。")
print("End")
  Cell In[3], line 4
    else:
    ^
IndentationError: expected an indented block after 'if' statement on line 2

これはエラーになる。なので、以下の文が正しい。

i = 10 
if i == 10:
    pass    
else:
    print("変数iは10ではありません。")
print("End")
End

pass命令を使えばエラーにならない。

2 正規表現

　正規表現とは「あいまいな文字列パターンを表現するための記法」である。例えば[0-9]{3}-[0-9]{4}という正規表現は一般的な郵便番号を表す。[0~9の3桁] + [-] + [0~9の4桁]という文字列パターンを短く表現できている。 　単にマッチするかどうかの判定だけではなく、正規表現を利用すれば、掲示板への投稿記事から有害なHTMLタグだけを取り除いたり、任意の文書からメールアドレスだけを取り出したり、といったこともできる。

2.1 基本

　正規表現によって表されたある文字列パターンを正規表現パターンという。正規表現パターンにマッチする文字列は1つだけとは限らない。正規表現の中でも特によく使うものについて、その記法を以下の表に示す。

2.2 練習問題

Table 1 を手がかりに以下の正規表現がどのような文字列にマッチしているか、読み解こう。

第1問

[\w.+-]+@([\w-]+\.)+[\w-]{2,}
Tip解答を見る
  • 一般的なメールアドレスにマッチする。例としてtaro.yamada+1@example.com等が挙げられる。
  • 各要素の分解
    • [\w.+-]+ : @ の前の部分。英数字・アンダースコアのほか、ドット、プラス、ハイフンが1文字以上続く。
    • @ : 文字通りの @ マーク。
    • ([\w-]+\.)+ : ドメインの前半部分。「英数字・アンダースコア・ハイフンの1回以上の繰り返し、ドット」という塊が1回以上繰り返される。
    • [\w-]{2,}: ドメインの末尾。英数字・アンダースコア・ハイフンが2文字以上続く。

第2問

https?://[\w.-]+(:\d{1,5})?(/[\w./-]*)?(#[\w-]+)?
Tip解答を見る
  • ポート番号やページ内のリンクがついている場合にも対応したURLにマッチする。
  • 各要素の分解
    • https?:// : http://またはhttps://。
    • [\w.-]+ : ドメイン名部分。
    • (:\d{1,5})? : ポート番号。：の後に数字が1から5桁。?によりその番号が0回か1回で一致。
    • (/[\w./-]*)? : パス部分。スラッシュの後に文字が0文字以上続く。
    • (#[\w-]+)? : ページ内のリンク。#の後に英文字やハイフンが1文字以上続く。?によりそれらが0回か1回で一致。

第3問

^(\.\.?/)?([\w-]+/)*[\w-]+\.(png|jpe?g|gif|webp)$
Tip解答を見る
  • 画像ファイルへのパスにマッチする。
  • 各要素の分解
    • ^ と $ : 行頭から行末まで全体が一致する必要がある。
    • (\.\.?/)? : 相対パスの指定。単に.を指定すると、任意の一文字になってしまうため、エスケープ\を付与。./か../が0回か1回マッチする。
    • ([\w-]+/)* : 途中のフォルダ階層。*により0回以上でマッチする。
    • [\w-]+ : 画像ファイル名。
    • \. : 拡張子前のドット。
    • (png|jpe?g|gif|webp) : 拡張子名。jpgまたはjpegが混在しているためe?でeが0回か1回マッチさせる。なお.jpgと.jpegはファイル形式として全く同じものである。

2.3 Pythonで正規表現を取り扱う

　ここからはPythonで正規表現を取り扱う方法についてまとめる。以下の例は文字列に含まれる電話番号を検索する例である。

import re

msg = "電話番号は080-111-9999です。"
ptn = re.compile(r"(\d{2,4})-(\d{2,4})-(\d{4})") #正規表現を準備、rは\エスケープシーケンスを文字として扱う
if result := ptn.search(msg) :
    print(result.group(0)) #マッチした文字列全体
    print(result.group(1)) #1つ目
    print(result.group(2)) #2つ目
    print(result.group(3)) #3つ目
else :
    print("見つかりませんでした。")
080-111-9999
080
111
9999

　正規表現を利用するには、reモジュールのcompile関数で正規表現パターンを準備する。

　正規表現パターンには、性質上\が多用される。文字列リテラルでのエスケープシーケンスとの衝突を防ぐために、raw文字列r"..."で表すのが安全であろう。

　compile関数は、戻り値として正規表現(Pattern)オブジェクトを返すので、そのsearchメソッドで検索を実行する。

ptn.search(string[, pos[, endpos]])
  • ptn : Patternオブジェクト
  • string : 検索対象の文字列
  • pos : 検索開始位置
  • endpos : 検索終了位置

　引数pos/endposを指定することで、文字列の検索範囲を限定することもできる。searchメソッドの戻り値はマッチング情報（Matchオブジェクト）、検索結果がなかった場合にはNoneである。Matchオブジェクト経由で取得できる情報は以下の表に示す。

　groupメソッドは、引く数を省略または0に指定した場合にマッチした文字列全体を返し、1以上の値を指定した場合はサブマッチ文字列を返す。サブマッチ文字列とは、正規表現の中で丸括弧で括られた部分にマッチした部分文字列のことであり、グループまたはキャプチャグループともいう。

これらの例をGeminiたんが作ってくれました。

import re

text = "TEL: 090-1234-5678 (担当: 山田)"
pattern = re.compile(r"(?P<area>\d{3})-(?P<mid>\d{4})-(?P<last>\d{4})")

# 5文字目〜20文字目の範囲だけ検索
m = pattern.search(text, pos=5, endpos=20)

if m:  # マッチしないと None になるためチェック
    # --- マッチした文字列の取得 ---
    print(m.group())          # '090-1234-5678'（引数なし or 0 で全体）
    print(m.group(1))         # '090'（1番目のグループ）
    print(m.group(1, 3))      # ('090', '5678')（複数指定でタプル）
    print(m.group("area"))    # '090'（名前指定も可能）

    # --- 位置（インデックス）の取得 ---
    print(m.start())          # 5（全体の開始位置）
    print(m.end())            # 18（全体の終了位置：スライス同様、この手前まで）
    print(m.span())           # (5, 18)（startとendのタプル）
    print(m.span(2))          # (9, 13)（2番目のグループ '1234' の範囲）

    # --- テンプレートへの埋め込み ---
    print(m.expand(r"市外局番:\g<area>, 末尾:\3"))
    # 出力: '市外局番:090, 末尾:5678'

    # --- 検索時の情報・グループ情報 ---
    print(m.pos)              # 5（指定した開始位置）
    print(m.endpos)           # 20（指定した終了位置）
    print(m.lastindex)        # 3（最後にマッチしたグループの番号）
    print(m.lastgroup)        # 'last'（最後にマッチしたグループの名前）

2.4 インデックス・スライス構文

　文字列から部分的な文字列を取り出すには、インデックス・スライス構文を利用する。

txt[index]
txt[start:end:step]
  • txt : 文字列
  • index : インデックス番号
  • start : 開始位置
  • end : 終了位置
  • step : ステップ（増減）

具体例を以下のコードで確認しよう。

title = "あいうえおかきくけこ"

print(title[2])
print(title[2:5])
print(title[2:])
print(title[:5])
print(title[:])
print(title[-7:-5])
print(title[::2])
print(title[::-1])

このようにインデックス・スライス構文を使用することで部分的に文字列を取り出すことができる。また引数に負の番号を与えれば、遡った位置から開始、終了を設定でき、stepに負の引数を与えれば逆順の文字列を得る。

　スライス構文は、内部的にはsliceオブジェクトとして処理される。sliceオブジェクトは、組み込み関数sliceで生成でき、indicesメソッドでインデックス表現に変換できる。

title = "あいうえおかきくけこ"

print(title[slice(-5, None, -1)])
print(slice(-5, None, -1).indices(len(title)))
かおえういあ
(5, -1, -1)

slice(-5, None, -1)は[-5::-1]と同じ意味である。(5, -1, -1)は5から-1未満まで-1方向にスライスするということである。

2.5 マッチした全ての文字列を取得

　search/matchメソッドで得られる結果は、何も最初にマッチした文字列1つだけである。マッチした文字列全てを取得したいなら、findall/finditerメソッドを利用する。

import re

msg = "電話番号は000-999-9999です。携帯は080-2222-3333です！"
ptn = re.compile(r"\d{2,4}-\d{2,4}-\d{4}")
results = ptn.findall(msg)
for result in results:
    print(result)
000-999-9999
080-2222-3333

findallメソッドの戻り値はマッチした文字列のリストである。マッチングの結果をMatchオブジェクトとして取得したいなら、finditerメソッドを利用する。

import re

msg = "電話番号は000-999-9999です。携帯は000-2222-3333です！"
ptn = re.compile(r"(\d{2,4})-(\d{2,4}-(\d{4}))")
results = ptn.finditer(msg)
for result in results:
    print(f"開始位置：{result.start()}")
    print(f"終了位置：{result.end()}")
    print(f"マッチング文字列：{result.group()}")
    print(f"市外局番：{result.group(1)}")
    print(f"市内局番：{result.group(2)}")
    print(f"加入者番号：{result.group(3)}")
    print("-----------------")

2.6 オプション

　Patternクラスをインスタンス化する際は、第2引数に検索オプションを渡すことができる。

具体例をいくつか見てみよう。まずは大文字・小文字を区別しないものである。

import re

msg = "仕事用はwings@example.comです。プライベート用はYAMA@example.comです。"
ptn = re.compile(
    r"[a-z009.!#$%&\'*+\=?^_{|}~-]+@[a-z0-9-]+(\.[a-z0-9-]+)*", 
    re.IGNORECASE)
results = ptn.finditer(msg)
for result in results:
    print(result.group())
wings@example.com
YAMA@example.com

続いてはマルチラインモードである。

import re

msg = "10人のインディアン。\n1年生になったら。"
ptn = re.compile(r"^\d*")
results = ptn.findall(msg)
for result in results:
    print(result)
10

^は行頭を表すので、これは10しか返されない。しかし、マルチラインモードを有効にすれば、

import re

msg = "10人のインディアン。\n1年生になったら。"
ptn = re.compile(r"^\d*", re.MULTILINE)
results = ptn.findall(msg)
for result in results:
    print(result)
10
1

　改行の直後の1までマッチするようになる。
